# Metadados do repositório de perfil

Este documento registra a separação entre os metadados do repositório de perfil `Jacson-Nascimento/Jacson-Nascimento` e os metadados históricos dos projetos científicos que anteriormente residiam em sua raiz.

## Regra canônica

O repositório `Jacson-Nascimento/Jacson-Nascimento` funciona como perfil acadêmico-profissional, índice de projetos e registro histórico de transição.

Os projetos científicos independentes possuem metadados próprios em seus repositórios canônicos. Em particular, o Modelo Axion Lotofácil possui continuidade em `Jacson-Nascimento/modelo-axion-lotofacil`.

## Preservação histórica do Axion

Os metadados da série documental v1.0 do Modelo Axion Lotofácil, DOI `10.5281/zenodo.21522330`, permanecem preservados neste repositório em:

- `lotofacil_axion/CITATION.cff`
- `lotofacil_axion/.zenodo.json`

A alteração dos arquivos `CITATION.cff` e `.zenodo.json` da raiz não modifica nem substitui o registro Zenodo já publicado, seus DOI ou os arquivos históricos associados.
