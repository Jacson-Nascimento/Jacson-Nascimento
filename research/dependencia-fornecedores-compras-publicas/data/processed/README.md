Este diretório pertence à cópia histórica pública da pesquisa de dependência de fornecedores.

Desde 23/08/2026, novas bases processadas, checkpoints e arquivos intermediários não devem ser adicionados aqui. A continuidade operacional ocorre no repositório privado `Jacson-Nascimento/dependencia-fornecedores-compras-publicas`.

Os arquivos já versionados permanecem preservados para proveniência. Novas saídas destinadas à publicação devem passar por minimização e revisão de dados antes de qualquer divulgação pública.

Consulte `../../../../PUBLIC_DATA_POLICY.md` para a política vigente.
