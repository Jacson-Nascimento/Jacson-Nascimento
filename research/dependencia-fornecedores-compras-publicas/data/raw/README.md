# Diretório histórico congelado

Este diretório pertence à cópia histórica pública da pesquisa de dependência de fornecedores.

Desde 23/08/2026, novas bases brutas não devem ser adicionadas aqui. A continuidade operacional ocorre no repositório privado `Jacson-Nascimento/dependencia-fornecedores-compras-publicas`.

Os arquivos já versionados permanecem preservados para proveniência. A presença histórica de um arquivo neste diretório não significa que ele seja recomendado como padrão atual de publicação de dados.

Consulte `../../../../PUBLIC_DATA_POLICY.md` para a política vigente.
